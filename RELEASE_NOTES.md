# RawlineMobile 1.1.4

# Вступайте в Telegram комьюнити, там общение и поддержка по нашим проектам: https://t.me/raw_comm

- DNS-правила: для выбранных сайтов можно задать свой DNS-сервер, через прокси или напрямую. Сайты пишутся как в NekoBox: domain:, full:, keyword:, regexp: и geosite:.
- В управлении серверами снова есть отдельные деплои qWDTT, CSQTT, MRTT, WDTT Plus и FreeTurn, рядом с деплоем WDTT Panel.
- Флаг сервера берётся из названия: подходит первый флаг в любом месте имени. Добавление подписки больше не запускает проверку серверов.
- На Android 7–13 DNS через туннель работает с актуальными корневыми сертификатами, qWDTT подключается и на старых версиях.
- Под кнопкой подключения у автовыбора виден сервер, который он выбрал, и подписка этого сервера.
- Android TV: пульт переходит в списки настроек, а группы и подписки перемещаются удержанием OK и стрелками.
- При выходе из выбора приложений для VPN и из настроек группы с несохранёнными изменениями появляется окно «Сохранить / Не сохранять / Отмена».
- В редакторе главного экрана блок при перетаскивании остаётся прозрачным и не закрывает соседние.
- Подсветка нажатия повторяет форму кнопок и пунктов меню.
- Окно деплоя открывается без моргания фона.
